# Crack Detection and Water Level Indicator in Dam

## 📌 Project Overview
This project is an IoT-based system designed to monitor dam safety by:
- Detecting cracks in dam structure
- Monitoring water level in real-time

## 🚀 Features
- Real-time crack detection
- Water level monitoring using ultrasonic sensor
- IoT-based alerts
- LCD display output
- Buzzer warning system

## 🛠️ Technologies Used
- ESP8266
- Ultrasonic Sensor
- Arduino IDE
- IoT (Blynk / Cloud)

## 📂 Project Structure
- report/ → Full project report
- presentation/ → PPT
- images/ → Model & results
- code/ → Arduino/Python code
